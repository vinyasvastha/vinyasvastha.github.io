# Vinyasvastha Trust — Official Website

Official static website for **Vinyasvastha Trust**, hosted via GitHub Pages at [https://vinyasvastha.github.io](https://vinyasvastha.github.io).

## Pages Included
- **Home (`index.html`):** Overview of Vinyasvastha Trust, core focus areas, citizen charter, and social channels.
- **About Us (`about.html`):** Trust profile, Indian Trusts Act (1882) governance, Vision, Mission, 8 codified aims and objectives, and non-discrimination charter.
- **Divyangjan Calculator (`divyangjan-calculator.html`):** Dedicated showcase for our assistive technology tool implementing Government of India Gazette Notification S.O. 1338(E) under the RPwD Act, 2016.
- **Theme Stylesheet (`style.css`):** Unified modern styling matching the Vinyasvastha color scheme.

## Quick GitHub Pages Deployment Instructions
1. Create a repository named `vinyasvastha.github.io` on GitHub.
2. Upload `index.html`, `about.html`, `divyangjan-calculator.html`, and `style.css`.
3. In **Settings** → **Pages**, set branch to `main` and folder to `/ (root)`.
4. Your site will automatically go live at `https://vinyasvastha.github.io`!
